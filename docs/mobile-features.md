# 移动端功能

项目标题右侧的加号新建该项目的会话。长按会话或点右侧菜单，可置顶、重命名、创建分支、归档或恢复。置顶会话集中展示在所有项目之前，保留真实电脑和项目归属；搜索也覆盖置顶内容。

分支从已完成的会话上下文创建，后续消息独立保存。正在执行时请先停止或等待完成。来源关系读取 Codex 原生 `forkedFromId`，刷新或重启后仍可查看。项目归属按明确 metadata 读取，不根据目录推断。

## 照片与近期图片

待发送附件横向滚动展示，每张照片均可预览和单独移除。文件仍受每条消息 6 个、每个 8 MB 的限制。

Android/iOS 可在 Settings → 通用点击“允许检测近期图片”。返回会话或从后台回来时，检测授权相册中最近 **5 分钟**的照片，最多提示 6 张。确认后上传到当前会话的附件，不自动发送；添加或忽略后保存图片 ID，避免重复提示。权限被拒绝或仅开放部分照片时，只检测系统允许访问的内容，手动附件选择仍可用。Web 不自动读取相册或剪贴板，请手动选择文件。

## Plan / Goal

聊天底部“功能”面板切换普通执行与 Plan。切换保留草稿和附件；Plan 请求通过 `turn/start.collaborationMode`，使用 Codex 内置模式指令。形成计划后点击“进入执行”，再发送执行指令。

Goal 使用 `thread/goal/get`、`set`、`clear` 原生接口，明确传入 `origin: user`。支持目标创建、修改、预算、暂停、继续、结束和清除；真实状态来自 Codex，并在重新进入会话时读取。功能依据实际 API 探测；不支持时显示原因，不以普通消息或拼接提示词模拟。

## 运行指标口径

- 状态来自真实任务、文本输出、工具和审批事件；结束后保留本轮最终数据。
- 上下文按 `thread/tokenUsage/updated.tokenUsage.last.totalTokens` 估算最近一次模型请求占用，以 `modelContextWindow` 为容量。累计会话 `total` 不用作上下文占用；压缩后随通知更新。没有通知或容量时显示暂无数据。
- 本轮用量是累计 `total` 相对本轮开始时基线的差值，展示输入、输出、缓存命中 token。首次接入已有会话而没有可靠基线时不伪造本轮数值。
- 速度统计本轮助手输出的 Unicode 字符，使用首个至最后一个文本片段的时间范围，最短按 1 秒计算。工具输出不计入；显示“约 N 字符/秒”，不把字符写成 token/s。
- 指标按机器和会话隔离，Agent 本地 SQLite 保留快照，断线后以带序号的快照和事件恢复，旧事件不重复累加。

协议依据：[官方 App Server 文档](https://developers.openai.com/codex/app-server)、[Goals 说明](https://developers.openai.com/cookbook/examples/codex/using_goals_in_codex)。实现以本机 `codex-cli 0.162.0-alpha.17.2` 生成的类型为准。
